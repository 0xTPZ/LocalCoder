# Benchmarks

Esta área registra fixtures, critérios e resultados de comparação de backends. A Missão 001 não
executa inferência nem baixa modelos.

Todo benchmark futuro deve registrar versão do runtime, modelo, quantização, hardware, contexto,
parâmetros, tempo, tokens, RAM/VRAM, estabilidade, resultado qualitativo, falhas e estado final
do runtime. Resultados não podem ser tratados como comparáveis quando as condições diferirem sem
justificativa.
