# Public status boundary — 069

LocalCoder is a foundation and research project, not a completed autonomous coding product.

## Implemented foundation

- Versioned project, roadmap, mission, task, action, verification and checkpoint schemas.
- Atomic JSON persistence, redaction, journaling, file locking and crash recovery.
- Audit store, recovery manager, deterministic tests and a heuristic secret scanner.
- Pluggable model gateway with structured-output validation and opt-in local model lab.

## Explicit limits

- No final model is selected by the core.
- No complete autonomous agent is implemented.
- No external project command execution or continuous automation is enabled by default.
- Model integrations remain optional and local configuration is required.

Run the documented unit tests and secret scan before experimenting. Never place credentials in repository files or use a development agent against an untrusted workspace without reviewing its safety policy.
